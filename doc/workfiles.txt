*workfiles.txt*  Work files per repo and worktree, kept out of the repo's git

==============================================================================
CONTENTS                                                  *workfiles*

Notes, plans, test scripts and experiments live in
<root>/<repo>/<worktree>/, outside the repo. Each checkout's tmp/ is a
symlink to its folder, git-excluded through info/exclude. If tmp/ is taken,
the link is tmp_workfiles in the checkout's git dir. The panel opens files
through the link, so their buffers belong to the checkout.

==============================================================================
OPTIONS                                                   *g:workfiles_root*

The root, read every time it's used: g:workfiles_root, else
$WORK_FILES_ROOT, else ~/workfiles. >
    let g:workfiles_root = '~/notes/work'
<
==============================================================================
COMMANDS

:WorkFiles[!]                                             *:WorkFiles*
    Toggle the panel with this repo's work files, opened at the current
    worktree (the one the cwd is in). Makes that worktree's folder and its
    tmp link first if they don't exist yet. With ! every repo under the root.

:WorkGrep[!] [query]                                      *:WorkGrep*
    fzf search this repo's work files (! every repo). Needs fzf.vim and rg.

==============================================================================
PANEL KEYS                                                *workfiles-keys*

    <CR>          open the file (closes the panel) / open or close a folder
    go            open the file, stay in the panel
    o / <Space>   open / close a folder
    a / A         new file / new folder in the folder under the cursor
    r / D         rename / delete (to the Trash, needs `trash`)
    y             copy the path
    p             up to the parent folder
    R             refresh
    q             close
    ?             show / hide help
